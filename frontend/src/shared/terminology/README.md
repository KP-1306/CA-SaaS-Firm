# Terminology projection

Per-tenant vocabulary resolution applied at every rendering edge, so that the
domain keeps a fixed internal vocabulary (AR ADR-013, TD §12.9).

A firm may rename the five configurable concepts — Vertical, Domain, Service,
Task Template and Assignment — and the change must appear everywhere,
including exports, emails, validation messages and the portal. That is only
achievable if every label passes through one projection point.

Empty by design. Owned by a later work package.
